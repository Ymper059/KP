## Система мониторинга температуры на выходе реактора

## Постановка задачи

Программа предназначена для мониторинга температуры на выходе химического реактора. Она вычисляет показатель качества Q(X), контролирует состояние процесса и выполняет статистический анализ выборки.

### Входные данные

- Параметр X — температура на выходе реактора, °C.
- Диапазон датчика X: 40–130 °C.
- Область определения формулы Q(X): 63 < X ≤ 130 °C
  (при X ≤ 63 аргумент логарифма X − 63 ≤ 0, Q не определена; программа выдаёт ошибку).
- Нормальное состояние: 65–100 °C.
- Количество измерений: N = 70.

### Формула преобразования Q(X)

$$
Q(X) =
\begin{cases}
3\ln(X - 65 + 2) + 10, & 63 < X < 65,\\
2(X - 82.5) + 48, & 65 \le X \le 100,\\
5\sqrt{X - 100 + 1} + 58, & 100 < X \le 130.
\end{cases}
$$

### Ручной расчёт

1. X = 90,20 °C: $Q = 2(90.20 - 82.5) + 48 = 63.40$
2. X = 110 °C: $Q = 5\sqrt{110 - 100 + 1} + 58 \approx 74.58$
3. X = 64 °C (ветка X < 65): $Q = 3\ln(64 - 65 + 2) + 10 = 3\ln 1 + 10 = 10.00$

Проверка границ:

- X = 65: $Q = 2(65 - 82.5) + 48 = 13.00$
- X = 100: $Q = 2(100 - 82.5) + 48 = 83.00$
